# 🏦 Vaults

Infinite Trading vaults are built to package advanced onchain strategy execution into simple deposit/withdraw user experiences.

## Vault families

1. **Uniswap auto-compounders (Base-focused in current deployment set)**
2. **Velodrome auto-compounders (Optimism-focused in current deployment set)**
3. **Agentic Managed Vaults (Infinite Trading Cloud signal + execution automation)**

## What users should expect

- transparent onchain interactions
- strategy-specific risk/return profiles
- periodic compounding or active rebalancing depending on product
- clear fee models defined by vault architecture

## About strategy descriptions

This documentation explains strategy intent and behavior without exposing proprietary implementation details.
